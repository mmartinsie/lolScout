# docs/ — GitHub Pages site

This folder is a static site meant to be served with **GitHub Pages** (Settings → Pages →
Source: *Deploy from a branch* → Branch: `master`, folder: `/docs`). Once that's enabled, it
publishes to `https://<your-username>.github.io/lolScout/`.

It has two independent pieces:

- **`index.html` + `style.css` + `app.js` + `ui.js`** — a browser demo of the pick recommender.
  `app.js` is a hand-ported copy of the scoring logic in
  [`../DataProcessing/data_processing.py`](../DataProcessing/data_processing.py) (same formula,
  same role rosters); `ui.js` wires it to the page. It runs entirely client-side against the
  bundled sample snapshot in `data/` — no server, no live scraping. **If you change the scoring
  formula or a role roster in `data_processing.py`, update `app.js` to match** — there's no
  shared source of truth between the two.
- **`assets/*.png`** — six pre-generated plots from the original thesis work (patch-wide
  win/ban/pick-rate bar charts, and two per-champion win-rate time series), shown as static
  samples of what the R analysis in [`../RStudio/`](../RStudio/) produces. They aren't
  regenerated by anything in this repo.

`bsc-thesis-computer-science-lol-data-modelling.pdf` and `bsc-thesis-mathematics-lol-time-series.pdf`
also live in this folder (linked from the main README) — GitHub Pages serves them directly at
`.../docs/<filename>.pdf`, which is what the demo page links to.

## Updating the sample data

`data/champInfoVersionCSV.csv` is a copy of
[`../DataProcessing/champInfoVersionCSV.csv`](../DataProcessing/champInfoVersionCSV.csv). It's a
copy rather than a symlink because GitHub Pages only serves files that exist under `docs/`.
Re-copy it here after refreshing the sample snapshot elsewhere in the repo:

```bash
cp DataProcessing/champInfoVersionCSV.csv docs/data/champInfoVersionCSV.csv
```
